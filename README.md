## Descripción
Este repositorio contiene la resolución del Trabajo Práctico 2. Es un sistema básico programado en Java para gestionar eventos universitarios, salas, actividades e inscripciones de estudiantes.

## Qué incluye el proyecto (Ejercicios resueltos)
El código cubre los 4 requerimientos pedidos en el TP:

* **Ejercicio 1 (Excepciones y Archivos):** Creación de la excepción `CupoExcedidoException` para limitar inscripciones. También se implementó la serialización para guardar y leer los datos de los eventos en un archivo.
* **Ejercicio 2 (Interfaces):** Uso de la interfaz `Certificable` para generar certificados de asistencia. Solo aplica para actividades prácticas (Talleres y Cursos), dejando afuera a las Charlas.
* **Ejercicio 3 (Genéricos y Wildcards):** Creación de métodos parametrizados para filtrar las listas de actividades por su tipo y calcular el costo de los materiales usando comodines (wildcards).
* **Ejercicio 4 (Hilos y Clases Anidadas):** La clase `TicketDeAcceso` se hizo anidada dentro de la inscripción. Además, se armó el hilo `EnvioTicketsThread` para que los tickets se envíen en segundo plano mientras el programa principal sigue mostrando datos por consola.
